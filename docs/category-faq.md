# FAQ на страницах категорий

В WordPress вопросы создаются в разделе FAQ: заголовок — вопрос, содержимое —
ответ. Для отдельного набора категории назначьте вопросам FAQ-тег. Установите
связи между чешским тегом, его переводами и переводами вопросов в Polylang.

Категории услуг и FAQ-теги — разные таксономии с разными ID. Фронт находит
исходную чешскую категорию по `translations.cs`, затем ищет связанный чешский
тег и запрашивает перевод этого тега для выбранного языка. ID категории и ID
FAQ-тега не смешиваются.

Если у категории нет подходящего тега, опубликованных вопросов или перевода
FAQ-тега, страница показывает общий FAQ выбранного языка. Этот же общий список
используется на главной, странице «О нас» и странице контактов. Контент другого
языка автоматически не подставляется. Если общий список пуст, блок скрывается.

На странице сначала загружаются 15 вопросов WordPress. Кнопка «Показать ещё»
запрашивает следующую страницу из 15 вопросов и добавляет её к списку. Когда
вопросы заканчиваются, кнопка скрывается. Ограничения первыми 100 записями нет.
Порядок — по возрастанию ID; новые вопросы из админки добавляются в конец.

## Исходные материалы

`content/faq-olga.json` — старый снимок материалов, не runtime-источник сайта.
Фронт загружает FAQ только из WordPress. Перед запуском новых языков нужно
сверить опубликованные записи и связи переводов в Polylang; правки редактора
после этого выполняются в админке.
