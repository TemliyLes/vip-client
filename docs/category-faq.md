# FAQ на страницах категорий

В WordPress вопросы создаются в разделе FAQ: заголовок — вопрос, содержимое — ответ.
Для отдельного набора категории назначьте вопросам тег FAQ, чешское название которого
совпадает с чешским названием категории услуг. Например, категория `Permanentní make-up`
использует вопросы с тегом FAQ `Permanentní make-up`.

Категории услуг и теги FAQ — разные таксономии с разными ID. Фронт находит тег по
чешскому названию категории, без таблицы фиксированных ID. Регистр и лишние пробелы
не учитываются. При переименовании чешской категории переименуйте и её тег FAQ.

Если подходящего тега нет, у него нет опубликованных вопросов или нет вопросов на
выбранном языке, страница показывает общий FAQ этого языка — тот же список, что
на главной, «О нас» и контактах. Сейчас общий список включает все опубликованные
FAQ выбранного языка, включая вопросы с тегами. Это не только вопросы без тегов.
Если общий список тоже пуст, блок скрывается.

Для словацкой версии свяжите переводы тегов FAQ и вопросов через Polylang.
Фронт использует связь переводов тега, а не совпадение словацких названий.
Чешский контент при отсутствии словацкого набора не подставляется: используется
общий словацкий FAQ.

На главной, «О нас» и контактах по-прежнему используется общий список.
Блок на странице категории загружается при SSR и сразу присутствует в HTML.

## Вопросы Ольги

Набор из `PALIY_FAQ_Olga.xlsx` содержит 107 вопросов на каждый язык:
60 — перманентный макияж, 30 — косметология, 17 — обучение.
Вопросы не разделяются по отдельным услугам: каждая услуга наследует весь
набор своей основной категории (`is_primary`), а не рекламного ярлыка.

Общий список загружается постранично до конца, без ограничения первыми
100 записями WordPress. Порядок — по возрастанию ID: новые вопросы созданы
в порядке исходной таблицы. Новые вопросы из админки добавляются в конец.
На десктопе FAQ состоит из двух независимых колонок; на мобильном — из одной.

Снимок исходных текстов и обоих переводов хранится в `content/faq-olga.json`.
Фронт читает вопросы только из WordPress: последующие правки контент-менеджера
в админке не требуют изменения этого файла. Прежние демонстрационные вопросы
перемещены в корзину, новые вопросы и теги связаны через Polylang.
