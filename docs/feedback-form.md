# Форма заявки

Общий `Button` с непустым `to` открывает ссылку. Без ссылки он становится
`button type="button"` и открывает общую модалку. `tag="span"` внутри карточек
и `type="submit"` форму не открывают. Для собственного обработчика предусмотрены
`:form="false"` или `@click.prevent`. Обычный `@click` выполняется перед стандартным
открытием — мобильное меню так закрывается перед показом формы.

`ReservioButton` сохраняет свою схему: ссылка Reservio, если она задана,
иначе форма с контекстом услуги/тарифа. Тариф передаёт ID родительской услуги;
название выбранного тарифа добавляется перед сообщением, если позволяет лимит WP.

Форма требует имя, телефон и сообщение. Телефон не привязан к маске `+420`:
допускаются чешские, словацкие и другие номера из 9–15 цифр. Имя и сообщение
проверяются с учётом UTF-8 лимитов установленного PALIY: 100 и 5000 байт.

Отправка: браузер → `POST /api/feedback` Nuxt →
`POST {runtimeConfig.public.apiBase}/wp-json/paliy/v1/feedback` WordPress.
Передаются введённые данные, язык, URL и заголовок страницы, ID услуги при наличии.
Автоматические повторы отключены. Новое открытие формы сбрасывает её состояние.

В PALIY 2.28.1 заявка сохраняется приватной записью `paliy_feedback` в разделе
«Заявки». Уведомление отправляется на `PALIY_FEEDBACK_EMAIL`, если он настроен,
иначе на `admin_email`. Успех API означает сохранение заявки; сбой почтового
уведомления пишется в журнал WordPress и не удаляет сохранённую заявку.

## Словацкая версия: WordPress обновлён

09.10.2026 активный PALIY обновлён на сервере до 2.28.1. Теперь он принимает
`cs/sk`. Выполнены изменения:

1. В `paliy_product_crop_create_feedback_rest` разрешён `sk` в проверке языка.
2. В `paliy_product_crop_render_feedback_fields` добавлена опция `sk` / `Slovenčina`.
3. В `paliy_product_crop_save_feedback_fields` разрешён `sk`, чтобы сохранение
   заявки в админке не заменяло язык на `cs`.
4. Добавлены словацкие тексты уведомления и ответа API.

Применено точечное обновление `2.28.0 → 2.28.1`:
`wordpress/update-paliy-feedback.py`. Оно заменяет только восемь заранее
проверенных фрагментов (один из них встречается дважды), сохраняет полный
исходник в `~/paliy-plugin-backups`, проверяет PHP-синтаксис и атомарно заменяет
файл с сохранением владельца и прав. Чешские тексты уведомления не меняются.
Языки формы после обновления — `cs/sk`.

Запуск на хосте или в контейнере WordPress, где установлены Python 3 и PHP CLI:

```sh
python3 update-paliy-feedback.py /absolute/path/to/wp-content/plugins/paliy-product-crop/paliy-product-crop.php
```

Сначала редактор WP откатил сохранение из-за недоступной внутренней проверки
сайта. Затем обновление применено через разрешённый пользователем SSH-доступ;
PHP-синтаксис проверен в контейнере `paliy-wordpress-1`, WPVibe подтвердил
активную версию 2.28.1. Проверка редактора WP не отключалась.

Активный файл на хосте:
`/var/www/paliy/wp-content/plugins/paliy-product-crop/paliy-product-crop.php`.
Резервная копия:
`/root/paliy-plugin-backups/paliy-2.28.0-o8l2y2gj.php`.
Полный установленный исходник с ресурсами сохранён в `wordpress/paliy-product-crop`.

Фронт передаёт настоящий язык формы `cs/sk`. Существующие тексты чешского
словаря не изменены; новые сообщения формы добавлены отдельно на обоих языках.

Реальные заявки при разработке не отправлялись: такой запрос создаёт запись
и отправляет почтовое уведомление.
