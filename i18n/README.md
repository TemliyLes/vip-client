# Čeština / Slovenčina

Используется `@nuxtjs/i18n` 10.6.0 и Vue I18n на Nuxt 4. Чешский язык (`cs`)
сохраняет существующие адреса. Словацкий (`sk`) использует `/sk`, например
`/sk/services/58`. Переключатель CS / SK есть в десктопной и мобильной шапке.
Он сохраняет текущую страницу и выбор языка в cookie `vip_locale`.
HTML `lang` меняется вместе с языком. Внутренние ссылки учитывают текущую локаль.

## Словари

- `locales/cs.json` — исходный статический текст без исправления опечаток, регистра,
  пробелов, переносов и существующих русских заглушек.
- `locales/sk.json` — те же ключи, все значения первоначально равны `""`.
  Для перевода заполните значение у соответствующего ключа. Пустая строка означает
  «перевод ещё не готов»; посетитель увидит чешский оригинал.
- `ui` — текст компонентов; ключ содержит путь компонента, тег и номер текстового
  фрагмента. Части заголовков вокруг `<br />` имеют отдельные ключи.
- `navigation` — пункты меню, `categoryPages` — описания категорий,
  `errors` — существующие сообщения об ошибках.
- `languageSwitcher` — подписи переключателя языка для доступности.

JSON обрабатывается как буквальный текст через функции сообщений Vue I18n.
`@`, `{}`, `|` и CRLF не интерпретируются как синтаксис перевода.
При выводе текста шаблонов применяется прежнее сворачивание пробелов Vue;
сами значения чешского JSON, включая исходные CRLF, сохраняются без изменений.

## Контент WordPress

Контент WordPress отображается напрямую из существующих ответов API при обоих
языках. В словарях хранится только текст, заданный в коде приложения.
Переводы контента будут настраиваться в WordPress. Выбор языка при запросе API
будет добавлен отдельно после определения формата переводов в WP.

`source/ui-manifest.json` содержит точные исходные статические строки и Git
revision для проверки сохранности. Новые строки могут указывать собственную
revision. Строки удалённых элементов помечены `active: false`; их исходные значения
сохраняются в словарях. Приложение этот файл не загружает.

## Проверка

```sh
npm run check:i18n -- --require-empty-sk
npm run build
```

После добавления переводов запускайте `npm run check:i18n` без флага. Проверка
сверяет исходные строки с Git, ключи обоих словарей, работу буквальных сообщений,
fallback, будущие переводы и отсутствие оставшегося текста в шаблонах.

Выбор модуля проверен через Context7 и официальную документацию:
[Nuxt I18n](https://i18n.nuxtjs.org/docs/getting-started/usage),
[переключение языка](https://i18n.nuxtjs.org/docs/guide/lang-switcher),
[fallback](https://i18n.nuxtjs.org/docs/guide/locale-fallback),
[функции сообщений Vue I18n](https://vue-i18n.intlify.dev/guide/advanced/function).
