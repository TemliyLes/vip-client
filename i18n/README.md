# Чешский, русский и английский

Приложение использует `@nuxtjs/i18n` 10.6.0 и Vue I18n на Nuxt 4. Чешский
(`cs`) остаётся языком по умолчанию без префикса; русский и английский используют
`/ru` и `/en`. Автоматический выбор языка по браузеру отключён.

Переключатель `CS / RU / EN` подготовлен в `app/components/ui/LanguageSwitcher.vue`,
но остаётся закомментированным в десктопном и мобильном меню. Чтобы показать его,
раскомментируйте компонент и импорт в `Desktop.vue` и `Mobile.vue`.

## Статические словари

- `locales/cs.json` — исходный чешский текст; исходные строки и форматирование
  сохранены для проверки по `source/ui-manifest.json`.
- `locales/ru.json` — русский перевод строк интерфейса.
- `locales/en.json` — английский перевод строк интерфейса.
- Во всех словарях одинаковые ключи. Тексты шаблонов, доступности, форм,
  ошибок и статических описаний категорий хранятся в них.

JSON передаётся Vue I18n как буквальный текст: `@`, `{}`, `|` и CRLF не
интерпретируются как синтаксис перевода. При выводе сохраняется прежнее
сворачивание пробелов Vue.

## Контент WordPress

Содержимое услуг, категорий, страниц, новостей, FAQ, видео и отзывов хранится
в WordPress и не входит в эти словари. Чешские записи остаются исходными;
их версии на русском и английском связываются с ними в Polylang. ID нужны
WordPress и REST API для этих связей, но в публичные адреса не попадают.

Публичные пути:

- категории: `/sluzby/<slug>`, `/ru/uslugi/<slug>`, `/en/services/<slug>`;
- услуги: `/sluzba/<slug>`, `/ru/usluga/<slug>`, `/en/service/<slug>`;
- новости: `/novinka/<slug>`, `/ru/novost/<slug>`, `/en/news/<slug>`;
- список новостей: `/novinky`, `/ru/novosti`, `/en/news`;
- страницы: `/o-nas`, `/ru/o-nas`, `/en/about`; `/kontakt`, `/ru/kontakty`, `/en/contact`.

Slug каждой опубликованной языковой записи должен быть уникальным, латинским,
нижнего регистра и с дефисами: чешский и русский тексты транслитерируются,
английский переводится. Текущие числовые адреса после перехода на эту схему
не обслуживаются и не перенаправляются.

На подключённом WordPress настроены `cs`, `en`, `ru`; чешский остаётся языком
по умолчанию. Русский добавлен, но у `ru` и `en` пока нет опубликованных
переводов контента. Язык `sk` удалён из Polylang. Ранее назначенные на него
156 записей/объектов и 15 терминов остались в базе без языка, а связи переводов
сняты. Для публичных маршрутов нужно создать и опубликовать `ru`/`en` переводы
с латинскими slug.

## Проверка словарей

```sh
npm run check:i18n
```

Проверка сверяет чешские исходные строки с Git, состав ключей трёх словарей,
буквальный вывод сообщений и наличие переведённых строк в шаблонах.
