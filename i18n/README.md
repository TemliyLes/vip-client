# Čeština / Slovenčina

Используется `@nuxtjs/i18n` 10.6.0 и Vue I18n на Nuxt 4. Чешский язык (`cs`)
сохраняет существующие адреса. Словацкий (`sk`) использует `/sk`, например
`/sk/services/58`. Переключатель CS / SK временно закомментирован в десктопной
и мобильной шапке. Сайт открывается на чешском: `detectBrowserLanguage: false`
отключает автоматический выбор по браузеру и старой cookie `vip_locale`.
Чтобы вернуть ручное переключение, раскомментируйте `<LanguageSwitcher />`
и его импорт в `app/components/menu/Desktop.vue` и `Mobile.vue`.
Менять конфигурацию для ручного переключения не требуется. SK-адреса и переводы
остаются доступны. Переключатель сохраняет текущую страницу и выбор языка в cookie.
HTML `lang` меняется вместе с языком. Внутренние ссылки учитывают текущую локаль.

## Словари

- `locales/cs.json` — исходный статический текст без исправления опечаток, регистра,
  пробелов, переносов и существующих русских заглушек.
- `locales/sk.json` — те же ключи со словацкими переводами. Бренды, контакты
  и неиспользуемый Lorem ipsum сохранены. Для новых пустых значений статического
  словаря применяется чешский fallback.
- `ui` — текст компонентов; ключ содержит путь компонента, тег и номер текстового
  фрагмента. Части заголовков вокруг `<br />` имеют отдельные ключи.
- `navigation` — пункты меню, `categoryPages` — описания категорий,
  `errors` — существующие сообщения об ошибках.
- `languageSwitcher` — подписи переключателя языка для доступности.

JSON обрабатывается как буквальный текст через функции сообщений Vue I18n.
`@`, `{}`, `|` и CRLF не интерпретируются как синтаксис перевода.
При выводе текста шаблонов применяется прежнее сворачивание пробелов Vue;
сами значения чешского JSON, включая исходные CRLF, сохраняются без изменений.

## Контент WordPress

В словарях хранится только текст, заданный в коде приложения. Переводы контента
WordPress создаются и связываются в Polylang в админке.

Услуги, категории, страницы, новости, FAQ, видео и отзывы подключены через `VIP Polylang REST` 1.1.0
(исходник и инструкция — `wordpress/vip-polylang-rest`). Фронт передаёт `lang=cs`
или `lang=sk` и использует поле `translations` для выбора ID перевода.
Например, `/services/291` ↔ `/sk/services/314`,
`/category/16` ↔ `/sk/category/63`.

Списки содержат только записи выбранного языка. Категории без опубликованных
услуг скрыты из списка; карточки без перевода не добавляются из чешского списка.
Если у открытой услуги/категории нет перевода, переключатель ведёт на главную
выбранного языка. Прямая ссылка на отсутствующий перевод возвращает 404.
Прямая ссылка с ID другого языка перенаправляется на ID связанного перевода.

При смене URL страницы заново загружают данные. Ключи `useAsyncData` содержат
язык и ID, а запоздавшие ответы предыдущего языка не записываются в текущий
список. На странице перевода категории статическое описание определяется по
ID чешской категории из `translations.cs`: исходный словарь сохраняется.

Все списки WordPress запрашиваются с выбранным языком. Новости также переключаются
по связанному ID. Страница «О нас» выбирает перевод страницы 125. Видео и отзывы
включены в перевод в Polylang. Английские записи не попадают в CS/SK-списки.

Изображения и видео назначены непосредственно SK-записям в WordPress: используются
исходные вложения и те же кадрирования. Фронт не запрашивает чешскую запись для
подстановки изображений или текста. Связанные видео указывают на SK-записи.

Созданы переводы всех опубликованных CS-записей: 24 услуги, 8 новостей,
6 FAQ, 6 отзывов, 8 видео и 3 страницы. Связи ID и снимки для сверки сохранены
в `artifacts/wpvibe-connection`. Тестовое название услуги 314 «Дрова» оставлено
по указанию владельца. Цены, сроки, файлы и чешские исходники не изменены.

`source/ui-manifest.json` содержит точные исходные статические строки и Git
revision для проверки сохранности. Новые строки могут указывать собственную
revision. Строки удалённых элементов помечены `active: false`; их исходные значения
сохраняются в словарях. Приложение этот файл не загружает.

## Проверка

```sh
npm run check:i18n
npm run build
```

Проверка
сверяет исходные строки с Git, ключи обоих словарей, работу буквальных сообщений,
fallback, будущие переводы и отсутствие оставшегося текста в шаблонах.

Выбор модуля проверен через Context7 и официальную документацию:
[Nuxt I18n](https://i18n.nuxtjs.org/docs/getting-started/usage),
[переключение языка](https://i18n.nuxtjs.org/docs/guide/lang-switcher),
[fallback](https://i18n.nuxtjs.org/docs/guide/locale-fallback),
[функции сообщений Vue I18n](https://vue-i18n.intlify.dev/guide/advanced/function).
